# LensLore

A premium photography journal platform focused on visual storytelling.

## Overview

LensLore is a personal photography journal built to preserve moods, seasons, and places. Driven by a dynamic JSON architecture, it shifts away from traditional static templates to offer a high-end, editorial photography experience. The platform features collection-based exploration, an immersive photo viewer, rich metadata capabilities, and a responsive dark/light mode ecosystem to showcase visual stories in their best light.

## Features

- Dynamic JSON-powered content rendering
- Collection-based photo discovery
- Editorial photo viewer
- Location-integrated storytelling
- Theme persistence
- Responsive design
- Filmstrip preview experience
- Interactive gallery filtering

To run the project locally, use:

```bash

```

*Or if you have serve installed globally:*

```bash
serve .
```
